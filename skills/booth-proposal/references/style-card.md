# Style card – template and rules

A style card turns a reference booth into reusable design ingredients. It describes how the reference looks, separated from what the reference says, so a proposal can borrow the look without copying another company's identity.

Reference booths chosen by clients are often average in execution: LED outlines, glossy surfaces, too many messages. The card therefore has two layers: what the reference does (its intent) and how a top designer would do it (Elevate). Proposals are built from the Elevate layer. Read references/art-direction.md first.

## Rules

- Describe only what is visible. If a photo is dark or partly blocked, say so instead of guessing.
- Give colours as approximate HEX values and name where each is used. Mark them "≈" because colours in photos shift with lighting.
- Several photos of the same booth make one card; different booths make different cards.
- The Do-not-copy list starts with: other companies' logos and wordmarks, their slogans and text, distinctive sculptural signature pieces, and the exact overall layout. The user may move items between Borrow and Do-not-copy.
- If the reference booth belongs to the client itself (their own previous booth), say so: its brand elements can be reused, but keep the Do-not-copy list for anything belonging to others.
- Without references there is no style card: the design territories in art-direction.md define each concept's design language.
- Check every visible feature against the cliché list in art-direction.md and give each one an Elevate line.

## Template

```
STYLE CARD S1 · v1 · Source: <file names>
Owner of the reference booth: <client's own booth | another company | unknown>

Mood: <one sentence>
What the client probably loves about it: <the intent worth keeping>

Palette
| Role | Colour | ≈ HEX | Where it appears |
| Base | … | … | … |
| Primary | … | … | … |
| Accent | … | … | … |
| Light / LED | … | … | … |

Form language: <main structures and shapes>
Materials and finishes: <…>
Lighting: <types, colour temperature, where>
Graphics and typography: <…>
Signature elements: <the 2–4 things that make it recognisable>

Borrow (proposed)
- …

Do not copy (proposed)
- …

Elevate (how a top designer would execute the same intent)
| Reference does | Intent | Elevated execution |
| e.g. LED strips outline the arch | Make the frame glow and read from afar | One continuous cove of indirect light inside a matte arch |

Fit with the client brand: <one or two sentences>
```
